## Privacidade e limitações
Este é um protótipo acadêmico. Não informe dados pessoais reais: o formulário de pedido usa GET, e seus campos podem aparecer na URL. Não há processamento real de pedidos ou pagamentos comprovado na versão examinada. O resumo de confirmação é ilustrativo.
