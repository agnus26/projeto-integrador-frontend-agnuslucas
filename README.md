# Meu Delivery

Projeto integrador front-end voltado à apresentação de cardápios digitais e à simulação de pedidos de uma lanchonete, inspirado na praticidade de aplicativos de delivery.

## Público e objetivo

Consumidores que desejam consultar produtos e preços e pequenos estabelecimentos que precisam divulgar suas opções de alimentação.

## Funcionalidades

- Página inicial e apresentação institucional.
- Cardápio por categorias, com descrições e preços.
- Formulário de pedido com quantidades e modalidade de pagamento.
- Página de confirmação demonstrativa com resumo estático.
- Página e formulário de contato demonstrativo.

## Tecnologias

- HTML5.
- CSS3.
- JavaScript informado pela equipe, mas sua implementação não foi confirmada na versão pública analisada.

## Como visualizar

```bash
git clone https://github.com/agnus26/projeto-integrador-frontend-agnuslucas.git
cd projeto-integrador-frontend-agnuslucas
```

Abra `index.html` no navegador. Para uma visualização por servidor local, se tiver Python instalado, execute:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## Privacidade e limitações

Este é um protótipo acadêmico. Não informe dados pessoais reais: o formulário de pedido usa GET, e seus campos podem aparecer na URL. Não há processamento real de pedidos ou pagamentos comprovado na versão examinada. O resumo de confirmação é ilustrativo.
