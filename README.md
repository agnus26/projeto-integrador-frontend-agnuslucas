# Meu Delivery

Projeto integrador front-end voltado à apresentação de cardápios digitais e à simulação de pedidos de uma lanchonete, inspirado em aplicativos de delivery.

## Público e objetivo

Facilitar a consulta de produtos e preços pelos consumidores e ajudar pequenos estabelecimentos a divulgar seus produtos.

## Funcionalidades

- Página inicial e apresentação do estabelecimento.
- Cardápio por categorias, com descrições e preços.
- Formulário de pedido.
- Escolha da forma de pagamento.
- Página de confirmação demonstrativa.
- Formulário de contato.
- Layout responsivo para computadores e celulares.

## Tecnologias

- HTML5
- CSS3
- JavaScript (previsto no projeto)

## Recursos CSS utilizados

- Seletores e pseudo-classes.
- Box Model.
- Flexbox.
- CSS Grid.
- Media Queries.
- Transições.
